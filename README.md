# Control Hub

Repository ini berisi kumpulan controller untuk berbagai proyek IoT dan AI.

## Struktur Direktori

- **[rc-car](./rc-car/)**: Controller web dashboard untuk mengontrol RC Car via MQTT (menggunakan suara, jari, tombol).
- **[robot-angklung](./angklung/)**: Controller untuk proyek Robot Angklung.

Setiap folder proyek memiliki dokumentasi (README) masing-masing. Silakan masuk ke masing-masing folder untuk melihat detail cara menjalankan dan menggunakan controllernya.
